# Abdullah Anees — Photography & Films

> *"We Don't Just Capture Moments. We Turn Them Into Memories."*

Official portfolio, cinematic film reel showcase, bespoke wedding cinema, editorial and commercial photography web application for **Abdullah Anees**.

---

## ✨ Features

- **Home**: Cinematic Hero with film grain aesthetics, 2026 Showreel video player modal, and key proof metrics (10+ Years, 450+ Heirloom Films, 8K DCI Archival).
- **About**: Artist monograph, visual philosophy, camera & lens specifications (RED V-Raptor 8K, Hasselblad H6D-100c, Cooke Anamorphic, ARRI Alexa), and international editorial credentials.
- **Services**: Disciplines breakdown (*Cinematic Wedding Films*, *Editorial & Bridal Couture Stills*, *Commercial & Brand Narratives*, *Destination Documentaries*) with full equipment specs and deliverables modals.
- **Portfolio**: High-fashion & wedding bento gallery with category filters (`All`, `Weddings`, `Fashion`, `Films`, `Commercial`, `Portraits`) and an interactive **Fullscreen Lightbox** with zoom, keyboard navigation (`Left`, `Right`, `Esc`), EXIF data, and direct WhatsApp style inquiry.
- **Packages & Live Investment Calculator**: Transparent collections (*The Heritage*, *The Royal Heritage*, *The Imperial Bespoke*) with interactive add-on selection that computes estimated totals and pre-fills WhatsApp booking notes.
- **Testimonials**: Attributable patron reviews and trust badges.
- **Contact & Booking**: Interactive booking inquiry forms, FAQ accordion, studio coordinates, and instant pre-filled WhatsApp chat launcher.
- **WhatsApp Concierge**: Persistent floating quick-action drawer for direct bookings.

## 🚀 Getting Started

### 1. Clone or Extract the Project
```bash
git init
git add .
git commit -m "Initial commit: Abdullah Anees Photography & Films"
```

### 2. Install Dependencies
```bash
npm install
```

### 3. Run Development Server
```bash
npm run dev
```
Open [http://localhost:3000](http://localhost:3000) in your browser.

### 4. Build for Production
```bash
npm run build
```
